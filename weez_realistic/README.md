# Weez

Weez is the new and improved Codex-compatible v2 animated orange-and-white tabby pet.

The package contains:

- `pet.json` — pet metadata with `spriteVersionNumber: 2`
- `spritesheet.webp` — an 8×11 RGBA atlas using 192×208 cells

The atlas includes all nine standard Codex pet animations plus 16 clockwise look directions. It is 1536×2288 pixels and has passed structural, transparency, chroma-cleanup, blind-direction, and independent visual QA.
